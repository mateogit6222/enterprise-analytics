Protección de Rutas (Angular Route Guards)

  • AuthGuard: Protege todas las rutas internas redirigiendo al login si no existe un token de sesión válido.
  • RoleGuard: Restringe el acceso a /dashboard y /reports únicamente a cuentas con rol ADMIN. Los usuarios estándar son redirigidos de forma transparente a /records.
  • Interceptors HTTP: Inyectan automáticamente las cabeceras Authorization: Bearer <token> y capturan errores 401/403 para renovar sesión o notificar al usuario.

3. Gestión de Registros y Validación Asíncrona de SKU

Componente DataTable, formulario reactivo con debounce y unicidad server-side

Validación Asíncrona del Código SKU

Cada registro corporativo posee un código de inventario o proyecto (SKU). Para garantizar que no se produzcan duplicados sin saturar el servidor:

  • Se aplica un operador debounceTime de 450ms sobre el campo SKU para esperar a que el usuario termine de teclear.
  • Se invoca el método asíncrono ApiRestService.checkSkuExists(sku) simulando una consulta REST a PostgreSQL.
  • Feedback UX visual:
    • Spinner azul: Comprobación asíncrona en curso en servidor.
    • Icono verde: Código SKU único y disponible.
    • Alerta roja: Código SKU ya en uso. El botón de guardar se bloquea automáticamente.

Funcionalidades de la DataTable Reutilizable

  • Búsqueda en vivo: Filtra simultáneamente por SKU, título, cliente o descripción.
  • Ordenación multicampo: Haz click en cualquier encabezado para ordenar ascendente o descendentemente.
  • Paginación dinámica: Elige entre 5, 10, 25 o 50 registros por página.
  • Eliminación con ConfirmDialog: Cuadro de diálogo modal que solicita confirmación explícita para evitar pérdidas involuntarias de datos.

4. Informes Corporativos y Exportación a PDF/CSV

Resumen tabulado previsualizable, jsPDF autoTable horizontal y UTF-8 BOM

Exportación a PDF Profesional (jsPDF + autoTable)

Los informes PDF generados desde el Centro de Informes o desde el listado de registros cuentan con estándares corporativos:

  • Orientación horizontal (A4 Landscape): Óptima para tablas con múltiples columnas de datos de negocio.
  • Diseño y branding corporativo: Encabezado azul marino (#0f172a), cabeceras de tabla en tono índigo (#6366f1) y filas alternas para máxima legibilidad.
  • Paginación oficial: Numeración dinámica en pie de página ("Página X de Y") y sellado de fecha/hora de generación.

Exportación a CSV con Soporte UTF-8 BOM para Excel

  • Los archivos CSV generados incorporan el prefijo UTF-8 BOM (\uFEFF).
  • Esto garantiza que Microsoft Excel (tanto en Windows como en Mac) reconozca correctamente caracteres españoles (tildes, eñes, símbolos de euro €) sin requerir conversiones manuales.
  • Delimitador de campos mediante punto y coma (;) acorde a los estándares de hojas de cálculo europeas.

Preguntas Frecuentes (FAQ)

¿Por qué no puedo ver el Dashboard ni el Generador de Informes?

El sistema implementa Control de Acceso Basado en Roles (RBAC). Esas dos secciones son exclusivas para cuentas con rol Administrador. Para probarlas, cierra sesión y accede con admin@enterprise.com.

¿De dónde provienen los datos que visualizo en la aplicación?

La plataforma utiliza una arquitectura híbrida: combina registros históricos procedentes de una API REST que simula PostgreSQL (SQL) y un stream reactivo que simula Firestore (NoSQL) mediante forkJoin.

¿Se guardan mis preferencias de accesibilidad si recargo el navegador?

Sí. El servicio centralizado AccessibilityService persiste la escala de tipografía y el modo de alto contraste en el almacenamiento local del dispositivo.

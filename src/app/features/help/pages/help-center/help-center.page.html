Protección de Rutas (Angular Route Guards)

  • AuthGuard: Protege todas las rutas internas redirigiendo al login si no existe un token de sesión válido.
  • RoleGuard: Restringe el acceso a /dashboard y /reports únicamente a cuentas con rol ADMIN. Los usuarios estándar son redirigidos de forma transparente a /records.
  • Interceptors HTTP: Inyectan automáticamente las cabeceras Authorization: Bearer <token> y capturan errores para garantizar integridad de sesión.

3. Gestión de Registros y Validación Asíncrona de SKU

Componente DataTable, formulario reactivo con debounce y unicidad server-side

Validación Asíncrona del Código SKU

Cada registro corporativo posee un código de inventario o proyecto (SKU). Para garantizar que no se produzcan duplicados sin saturar el servidor:

  • Se aplica un operador debounceTime de 450ms sobre el campo SKU para esperar a que el usuario termine de teclear.
  • Se invoca el método asíncrono ApiRestService.checkSkuExists(sku) validando contra Supabase o el dataset en memoria.
  • Feedback visual accesible: spinner durante comprobación, marca de verificación verde cuando está libre o alerta roja si está duplicado.

Funcionalidades de la DataTable Reutilizable

  • Búsqueda debounced: Filtra simultáneamente por SKU, título, cliente o descripción.
  • Avatares de Responsable: Cada fila incorpora la miniatura vectorial optimizada del responsable asignado.
  • Paginación dinámica: 5, 10, 25 o 50 registros por página con selección múltiple y exportación a CSV.

Preguntas Frecuentes (FAQ)

¿Por qué no puedo ver el Dashboard ni Informes?

El sistema implementa Control de Acceso Basado en Roles (RBAC). Esas secciones son exclusivas para cuentas con rol Administrador. Para probarlas, accede con admin@enterprise.com.

¿De dónde provienen los datos de la app?

La plataforma conecta directamente a Supabase Cloud (PostgreSQL), con un mecanismo inteligente de zero-downtime fallback en memoria para garantizar disponibilidad total tanto en local como en Vercel.

¿Seguridad y Políticas RLS?

Las tablas de Supabase cuentan con Row Level Security (RLS) activado para salvaguardar la privacidad de las operaciones corporativas.
